# chaptercutter
An app that lets the user input an int for the lower limit of word count that a chapter has, and a .docx file (i.e: source.docx) which has the first line containing only an int. The app then generate a new .docx file (i.e: processed_source.docx) that has been cut into chapters (marked by "\n\nChương n+i\n\n" with n-the int in the first line)
